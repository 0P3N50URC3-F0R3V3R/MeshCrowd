Letöltés

Három darab, mind ingyenes: a szerver, amit te üzemeltetsz, egy asztali kliens Windowsra és egy Android-alkalmazás. Böngészővel is használhatod.

Szerver

0.9-es verzió · Windows, Linux, macOS

A MeshCrowd szerver beépített webes klienssel. Egy Node.js folyamat és egy SQLite adatbázis.

  • Hordozható Windows-csomag saját Node.js-sel
  • Forráscsomag Linuxra és macOS-re (Node.js 22.5 vagy újabb)
  • HTTPS automatikus tanúsítvánnyal
Szerver letöltése (Windows) Forrás letöltése (Linux / macOS)

Asztali kliens

Windows, hordozható · Electron 44

Hordozható alkalmazás tálcajelvénnyel, natív értesítésekkel és tanúsítvány-rögzítéssel. Nem hoz magával szervert, csak egy ablakot a tiédre.

  • Nincs telepítő: csomagold ki és futtasd a MeshCrowd.exe-t
  • A beállítások a saját data mappájában maradnak
  • Kicsomagolva nagyjából 340 MB

3.12-es verzió · Android 8.0 vagy újabb

Futtasd a saját szervered

Válaszd a gépednek megfelelő utat. A telepítési útmutató mindent részletesebben leír.

  1. Csomagold ki a szervercsomagot bárhová.
  2. Kattints duplán a start-server.bat fájlra. A mellékelt Node.js-t használja.
  3. Nyisd meg a https://localhost:8443 címet, és fogadd el egyszer a tanúsítvány-figyelmeztetést.
  4. Regisztrálj. Az első fiók lesz a tulajdonos, teljes adminjogokkal.

Hogy más eszközök is csatlakozhassanak, állítsd a data/config.json fájlban a publicHost értékét a LAN-címedre az első indítás előtt.

node --version        # 22.5 vagy újabb
npm install
npm start

Vagy futtasd a ./start-server.sh szkriptet. A szerver az első indításkor létrehozza a data/ mappát az adatbázissal, a konfigurációval és egy önaláírt tanúsítvánnyal.

{
  "publicHost": "chat.example.com",
  "useHttps": true,
  "serverCrt": "/etc/letsencrypt/live/chat.example.com/fullchain.pem",
  "serverKey": "/etc/letsencrypt/live/chat.example.com/privkey.pem",
  "turn": { "enabled": true, "externalIp": "203.0.113.10" }
}

A routereken és NAT-on átmenő hívások a beépített STUN/TURN szervert használják. Futtasd a setup-turn.bat-ot (Windows) vagy a setup-turn.sh-t (Linux): elmenti a beállításokat, megnyitja a tűzfalat, és megmondja, mely portokat kell átirányítani (3478 UDP és TCP, 49152-49999 UDP). Lásd: STUN és TURN.

TLS-t lezáró fordított proxy mögött állítsd a "trustProxy" értékét a proxyk számára, és továbbítsd a Host és X-Forwarded-Proto fejléceket. Lásd: TLS és fordított proxyk.

Az Android-alkalmazás telepítése

  1. Töltsd le az APK-t a telefonodra és nyisd meg. Az Android egyszer megkér, hogy engedélyezd a telepítést a böngészőből vagy a fájlkezelőből.
  2. Nyisd meg az alkalmazást és írd be a szervered címét, például chat.example.com vagy 192.168.1.44:8080.
  3. Az önaláírt tanúsítványt egyszer, az ujjlenyomata alapján fogadod el, amit összevetsz azzal, amit a szerver indításkor kiír.
  4. Jelentkezz be. Opcionálisan kapcsold be a UnifiedPush-t a Te › Android-alkalmazás alatt az azonnali értesítésekhez.
