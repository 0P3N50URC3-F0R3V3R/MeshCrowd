Everything in one place

A community platform that feels familiar from the first minute

If you have used a modern chat app you already know where things are. The difference is that this one belongs to you.

#general
  • Eight channel types: public, private, announcement, read-only, voice, stage, forum and encrypted Notes.
  • Threads off any message, forum channels made of posts, pins, replies, forwards and link previews.
  • Fast search across text, usernames, channel names and file names.
Lounge · voice
  • Voice, camera and screen share in channels and private calls, all peer to peer.
  • Quality presets from Mobile (8 kHz) to HD Music (48 kHz stereo), chosen when the channel is created.
  • Optional RNNoise noise suppression that runs on your own device.
  • Built-in STUN and TURN so calls reach people behind routers and NAT, with no third-party service and a one-click setup script.
#general · /roll
  • Slash commands published by any bot, with typed options and a popup in the composer.
  • Private answers that only you can see and that are never stored.
  • Token API and signed webhooks for n8n, scripts and your own tools. One bot can also be an AI chat partner.
Server Settings · AutoMod
  • AutoMod for blocked words, links, mass mentions, spam and capitals, with optional timeouts.
  • Rules screening with questions that hand out roles, and verification levels for new accounts.
  • Age-restricted channels with a one-time click-through, no ID checks and no third parties.
Server Settings · Insights
  • Insights computed from what already exists: growth, busiest channels and hours, most active members.
  • Roles with real permissions, per-channel overrides and an audit log of what moderators did.
  • Server templates to start new servers from a proven structure.
Midnight Purple
  • Per-user themes with presets, your own colors, fonts and a background gradient.
  • Role icons as an emoji or an image, shown next to names.
  • Profile cards, banners, custom status and a server rail you can arrange in folders.

Yours, end to end

Built so that you stay in control

On your hardware

Everything lives in a data/ folder next to the server. Copy it and you have a backup.

No tracking

No analytics, no ads and no external fonts or scripts. The client loads nothing from a CDN.

Encrypted by default

HTTPS and WSS everywhere, bcrypt passwords, optional TOTP and revocable sessions.

Up and running

From download to first message in minutes

Download and start

Unpack the server and run the start script. It ships with its own Node.js runtime on Windows.

npm install
npm start

Open and register

Visit the address, accept the certificate once and create the first account. It becomes the owner.

https://localhost:8443

Invite your people

Create a server, copy an invite link and share it. Voice works on a LAN out of the box.
