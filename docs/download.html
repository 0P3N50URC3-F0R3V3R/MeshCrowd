Quick start

Run your own server

Pick the path that matches your machine. The installation guide covers everything in more detail.

  1. Unzip the server bundle anywhere.
  2. Double-click start-server.bat. It uses the bundled Node.js.
  3. Open https://localhost:8443 and accept the certificate warning once.
  4. Register. The first account becomes the owner with full admin rights.

To let other devices connect, set publicHost in data/config.json to your LAN address before the first start.

node --version        # 22.5 or newer
npm install
npm start

Or run ./start-server.sh. The server creates data/ on first start with the database, the configuration and a self-signed certificate.

{
  "publicHost": "chat.example.com",
  "useHttps": true,
  "serverCrt": "/etc/letsencrypt/live/chat.example.com/fullchain.pem",
  "serverKey": "/etc/letsencrypt/live/chat.example.com/privkey.pem",
  "turn": { "enabled": true, "externalIp": "203.0.113.10" }
}

Calls across routers and NAT use the built-in STUN/TURN server. Run setup-turn.bat (Windows) or setup-turn.sh (Linux): it saves the settings, opens the firewall and tells you which ports to forward (UDP and TCP 3478, UDP 49152-49999). See STUN and TURN.

Behind a reverse proxy that terminates TLS, set "trustProxy" to the hop count and forward Host and X-Forwarded-Proto. See TLS and reverse proxies.

Installing the Android app

  1. Download the APK on your phone and open it. Android asks you to allow installs from your browser or file manager once.
  2. Open the app and type your server address, for example chat.example.com or 192.168.1.44:8080.
  3. A self-signed certificate is trusted once, by its fingerprint, which you compare with the one the server prints at start.
  4. Sign in. Optionally turn on UnifiedPush under You › Android app for instant notifications.
